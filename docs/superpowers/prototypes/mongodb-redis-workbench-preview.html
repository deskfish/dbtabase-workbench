Database Workbench — MongoDB & Redis UI 预览

基于现有 MySQL/PostgreSQL 壳层扩展 · 点击上方切换场景

现有：MySQL / PostgreSQL（关系型）

  • 对象树：数据库 → Schema → 表 / 视图
  • 工作区标签：SQL 查询 · 表数据 · 表结构编辑
  • 数据模型：固定列 + 行，SQL 筛选排序
  • 结构编辑：字段/索引/外键 + DDL 三阶段
  • 查询语言：SQL（Monaco 编辑器）

扩展：MongoDB（文档型）

  • 对象树：数据库 → 集合（Collection）
  • 工作区标签：文档浏览 · 聚合查询 · 集合结构
  • 数据模型：BSON 文档，嵌套字段，动态 Schema
  • 结构编辑：索引管理 + Validator（只读/有限编辑）
  • 查询语言：Find Filter JSON + Aggregation Pipeline

扩展：Redis（键值型）

  • 对象树：DB 索引 (0–15) → 键列表（SCAN 分页）
  • 工作区标签：键详情 · 命令台
  • 数据模型：Key + Type + Value（string/hash/list/set/zset/stream）
  • 结构编辑：无 Schema；支持 TTL 设置、键 CRUD
  • 查询语言：Redis 命令（非 SQL）

统一壳层（不变的部分）

  • 连接侧栏：个人/团队连接、加密存储、分享复制
  • 顶部栏：标签页、连接状态、驱动类型徽章
  • 能力声明：capabilities 驱动 UI 显隐，前端不猜测
  • 安全链路：超时、行数/键数限制、危险操作确认
  • 结果组件：表格/JSON 视图复用 ResultGrid 变体
