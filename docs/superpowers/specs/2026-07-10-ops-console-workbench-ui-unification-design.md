# Ops Console 工作台 UI 统一设计

日期：2026-07-10

状态：已确认，等待书面规范复核

## 背景

Ops Console 已把连接中心、数据库、日志和设置合并到同一个应用外壳，但四个区域仍保留两套视觉语言。数据库页是紧凑的桌面工作台：细边框、固定工具栏、分栏导航、标签页和高密度数据区域。连接中心、日志和设置页仍以大标题、悬浮卡片、渐变背景和页面级表单为主，信息密度、控件外观和交互方式均不一致。

本次以数据库页为唯一 UI 基准，重新设计连接中心、日志和设置三页，形成完整的共享工作台组件体系。保留现有业务功能、权限和数据流，不重写后端业务语义。

## 目标

1. 连接中心、日志和设置采用与数据库页一致的桌面工作台布局和视觉密度。
2. 建立可复用的工作台框架、工具栏、侧栏、标签、表格、状态和反馈组件。
3. 所有输入、选择、复选、文件上传、菜单和弹窗通过项目 UI 组件呈现，不暴露浏览器默认控件外观。
4. 保留语义化 HTML、键盘操作、可见焦点和屏幕阅读器信息。
5. 保留当前未提交的日志、团队和用户管理功能改动，在现有代码上整合，不重置工作树。
6. 桌面端保持高信息密度，小屏提供可折叠导航和可滚动工作区。

## 非目标

- 不修改数据库查询、日志索引、SSH、团队权限或连接加密的后端语义。
- 不重新设计登录页和数据库页业务工作区。
- 不增加新的日志分析能力、后台任务系统或数据库功能。
- 不为了统一视觉而把日志、连接和设置耦合到数据库业务组件中。
- 不引入第三方 UI 组件库。

## 方案选择

### 采用：共享工作台组件与页面重构

抽取独立的工作台 UI 层，再把连接中心、日志和设置映射到同一套布局原语。这样既能达到视觉统一，又能保持各业务模块的状态和数据请求边界。

### 未采用：只调整 CSS

只换颜色和圆角不能解决页面结构差异，仍会保留卡片后台与数据库工作台并存的问题。

### 未采用：直接复用数据库内部外壳

数据库内部外壳携带连接、查询标签和编辑器状态。把其他页面嵌入其中会造成业务耦合，后续修改数据库工作区时容易破坏日志和设置。

## 统一视觉语言

- 页面背景使用现有浅蓝灰 token，工作区表面以白色和浅灰蓝分层。
- 使用 1px 细边框表达区域关系，阴影只用于模态层，不用于普通内容面板。
- 常规圆角控制在 8–12px；表格、工具栏和分栏边界优先使用直线结构。
- 页面不再使用超大标题。模块名称放入紧凑顶栏，辅助信息使用 11–12px 等宽或弱化文字。
- 主操作使用天蓝色，危险、警告、成功和实时状态沿用现有语义 token。
- 控件高度统一为 32px 或 36px，数据行采用紧凑密度。
- 移除页面级渐变装饰、悬浮大卡片、过度留白和胶囊式主导航。
- 深色表面只用于日志 Tail、日志正文或其他需要终端语义的内容区。

## 共享组件体系

共享组件放在 `web/src/features/ui`，只负责视觉和通用交互，不直接请求业务 API。

| 组件 | 责任 |
| --- | --- |
| `WorkbenchFrame` | 提供模块顶栏、可选侧栏、主工作区和小屏折叠结构 |
| `WorkbenchToolbar` | 放置标题、状态、搜索、主要操作和上下文操作 |
| `WorkbenchSidebar` | 提供分区标题、筛选、列表、空状态和底部操作区 |
| `WorkspaceTabs` | 提供数据库式标签导航、激活态、关闭或新增入口 |
| `DataGrid` | 统一表头、行高、选中、悬停、空状态和操作列 |
| `TextField` / `TextAreaField` | 统一文本输入、标签、说明、错误和禁用态 |
| `SelectControl` / `ComboboxControl` | 继续使用项目自绘选择控件，不显示原生下拉菜单 |
| `Checkbox` | 使用项目复选组件和自绘标记，保留语义化 input |
| `FileField` / `Dropzone` | 隐藏原生文件输入，提供拖放、选择、文件摘要和错误状态 |
| `FormDialog` / `ConfirmDialog` | 统一创建、编辑、删除和权限确认流程 |
| `StatusBadge` | 表示连接、范围、角色、Tail 和任务状态 |
| `EmptyState` | 在侧栏、表格和工作区中提供尺寸一致的空状态 |

“不使用原生组件”指用户界面不暴露浏览器默认样式和默认弹层。底层继续使用语义化 `input`、`button`、`table` 等元素，以保证可访问性和表单行为。

## 页面设计

### 连接中心

布局采用左侧连接导航与右侧数据工作区：

- 顶栏显示“连接中心”、当前结果数量和“新建连接”。
- 左侧包含连接类型、个人/团队范围、自绘搜索框和连接统计。
- 右侧使用统一 `DataGrid` 展示名称、驱动、范围、主机、凭据状态和操作。
- 行点击选择连接；编辑和删除放在行操作菜单或工具栏中，避免每行堆叠多个大按钮。
- 新建和编辑继续使用完整的自绘对话框；数据库与 SSH 字段按连接类型切换。
- 空数据、加载失败、权限不足和无搜索结果分别呈现明确状态。

### 日志

布局采用左侧会话列表与右侧标签工作区：

- 顶栏显示“日志工作台”、当前会话范围、索引条目数和新建会话入口。
- 左侧提供会话搜索、个人/团队筛选、会话列表与底部新建操作。
- 新建会话移入 `FormDialog`，不再常驻占据页面空间。
- 右侧固定标签为“日志检索”“本地导入”“SSH 文件”“实时 Tail”；默认进入日志检索。
- 本地导入使用自绘 Dropzone，显示文件名、大小、服务、节点和上传状态。
- SSH 文件页使用紧凑工具栏、远程路径面包屑和文件表格；导入、Tail 和批量导入从选中项触发。
- 实时 Tail 使用深色终端区，顶部统一放置连接状态、过滤、行数和停止操作。
- 日志检索使用紧凑查询工具栏、范围摘要和统一数据网格。
- 没有会话时，右侧显示单一工作区空状态，不再同时出现多个卡片空状态。

### 设置

布局采用左侧设置导航与右侧管理工作区：

- 顶栏显示“设置”、当前分区和与当前页面相关的主要操作。
- 左侧固定“个人资料”“团队”“用户”三个分区，并显示必要的权限提示。
- 个人资料采用紧凑属性表和团队列表，不使用两张悬浮卡片。
- 团队页使用团队表格；成员管理在专用对话框或右侧详情区域完成。
- 用户页使用统一数据网格；创建和编辑使用 `FormDialog`，团队分配使用自绘复选与角色选择组件。
- 无系统管理员权限的分区保持路由保护，并提供明确的无权限状态。

## 应用外壳调整

保留现有 Ops Console 全局侧栏和账号顶栏，但减少装饰性阴影和渐变，使其与数据库工作台的线性结构一致。数据库页仍保留自己的专业工作区；连接、日志和设置通过共享 `WorkbenchFrame` 获得相同的内部顶栏和分栏节奏。

全局侧栏负责模块切换，页面内部侧栏只负责当前模块的筛选或分区，两者在层级、宽度和背景色上必须有明确区别。

## 状态与数据流

- 页面数据请求、权限判断和提交函数保持在现有业务页面或 hooks 中。
- 共享 UI 组件通过 props 接收数据、状态和回调，不依赖具体 client。
- 加载、成功、错误和禁用状态必须在对应控件或工作区内呈现，避免只在页面顶部显示孤立消息。
- 会话、连接、团队或用户选择通过稳定 ID 管理，视觉组件不复制业务状态。
- 对话框提交成功后保持现有刷新与选中行为；失败时在对话框内保留用户输入并显示错误。

## 响应式与可访问性

- 1200px 以上保持完整双栏工作台。
- 760–1199px 缩窄内部侧栏，并允许表格横向滚动。
- 760px 以下内部侧栏变为可打开的抽屉，工具栏操作允许折叠到菜单。
- 所有操作可通过键盘到达，焦点顺序与视觉顺序一致。
- 自绘选择、标签、菜单、对话框和文件控件提供正确的 ARIA 名称、状态和键盘行为。
- 焦点环使用现有 accent token；颜色不是状态的唯一表达方式。
- 动效遵循 `prefers-reduced-motion`。

## 验收标准

1. 连接中心、日志和设置在 1440px 桌面截图中与数据库页属于同一视觉系统。
2. 三页不再出现大标题卡片后台、页面级渐变装饰或普通内容面板的厚重阴影。
3. 所有选择、文件、复选、文本、弹窗和菜单均通过共享 UI 组件呈现，无浏览器默认外观。
4. 日志的会话、本地上传、SSH 浏览/导入、实时 Tail 和搜索功能保持可用。
5. 连接的筛选、搜索、新建、编辑和删除功能保持可用。
6. 设置的个人资料、团队、成员、用户和团队分配功能保持可用，权限保护不回退。
7. 空状态、加载态、失败态、禁用态和成功反馈完整且风格一致。
8. 375px、768px 和 1440px 三档视口无内容遮挡；数据表允许受控横向滚动。
9. 键盘焦点、标签、对话框和选择控件通过现有可访问性测试要求。
10. 相关 Vitest、TypeScript 检查和生产构建通过，并完成登录后的三页浏览器回归截图对照。

## 测试策略

- 为共享工作台组件增加渲染、键盘操作、禁用态和 ARIA 测试。
- 更新连接、日志、设置页面测试，覆盖主要功能和空状态。
- 运行前端单测、类型检查和 Vite 构建。
- 使用真实部署数据验证连接筛选、日志完整流程和设置权限流程。
- 分别在 375×812、768×1024 和 1440×1000 进行视觉回归。
- 对照数据库页检查顶栏、侧栏、控件高度、边框、间距、表格密度和状态样式。
