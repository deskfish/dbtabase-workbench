# Database Workbench 完整改版设计

## 问题

当前工作台已经具备 MySQL/PostgreSQL 连接、查询、数据浏览和基础修改能力，但连接导航、对象浏览和工作区层级不统一；个人与团队连接同时占用侧栏，分享与导入概念混乱；数据预览、查询和结构管理缺少统一组件及完整的数据库安全链路。

本次以用户提供的四张参考图为整体视觉与交互基准，完成专业数据库管理工作台，而不是只替换样式。

## 目标

- 统一顶部、连接栏、对象栏、标签页、工具栏、表格、分页、弹窗与状态反馈。
- 个人连接和团队连接互斥展示，完成幂等分享与“复制到个人”。
- 完成表数据预览、组合筛选、排序、列显示、密度、分页、CSV 和行编辑。
- 完成 SQL 查询工具栏、编辑器、结果区和可调分栏。
- 完成字段、索引、约束、外键、权限和 DDL 浏览。
- 完成可视化表结构编辑、DDL 预览、校验、风险确认与执行。
- 同时支持 MySQL 与 PostgreSQL，并保留现有网络与查询安全限制。

## 非目标

- 不增加登录、账号体系、角色权限管理或审计管理后台。
- 不增加数据库监控、慢查询分析、备份恢复或数据迁移任务。
- 不尝试完整复刻 Navicat 的全部能力。
- 昵称仍是个人连接归属和变更审计标识，不作为安全身份认证。

## 信息架构

### 顶部工作区

- 左侧显示产品标识和“数据库管理”。
- 中间显示可关闭的 SQL、数据表和结构编辑标签。
- 右侧显示当前数据库类型/版本、连接状态和个人入口。

### 第一侧栏：连接

- 平时只展示个人连接。
- 标题显示“连接：个人连接”和“团队连接 N”入口。
- 提供连接/表搜索、新建连接和刷新。
- 个人连接采用统一列表项：状态点、名称、类型、主机、默认数据库、连接状态。
- 悬停操作为分享、编辑、删除；已分享显示明确状态且不可重复创建。
- 团队连接不在侧栏常驻，通过居中弹窗查看。

### 第二侧栏：数据库对象

- 上半区列出数据库并支持切换。
- 下半区按 Schema 展示表、视图、函数、索引、序列和类型。
- 节点支持数量、展开/折叠、搜索、右键菜单和当前选中状态。

### 主工作区

支持三类标签：SQL 查询、表数据预览、表结构编辑。不同工作区共享按钮、选择器、表格、分页、空状态、错误反馈和确认弹窗组件。

## 连接交互

### 新建个人连接

- 新建连接默认属于当前昵称的个人连接。
- 成功后立即出现在个人列表，并可直接连接。
- 密码按现有加密规则存储，服务端和日志不返回明文。

### 分享到团队

- 个人连接行提供“分享到团队”按钮。
- 服务端按个人连接来源 ID 幂等创建团队副本。
- 成功后个人连接显示“已分享”，团队连接数量立即更新。
- 再次操作返回现有团队记录，不创建重复数据。
- 后续修改个人连接不会静默覆盖已经分享的团队副本。

### 复制到个人

- 点击“团队连接 N”打开团队连接弹窗。
- 弹窗支持名称/主机/数据库搜索、数据库类型和复制状态筛选。
- 每行显示名称、类型、主机、默认数据库、共享人、更新时间和状态。
- 操作为“复制到个人”；复制成功后团队记录保留，个人列表增加独立副本。
- 复制按团队来源 ID 与当前昵称幂等；已有副本显示“已在个人”。
- 复制出的个人连接使用新 ID，可独立编辑且不影响团队副本。
- 产品文案不再出现“导入”或“迁移”。

## 数据预览

- 顶部展示完整表名、数据库类型、估算行数、字段数、主键和最近耗时。
- 二级标签包括数据预览、字段结构、索引、关系、权限和 DDL。
- 数据工具栏包括搜索、组合筛选、排序、显示列、密度、刷新、CSV 和新增行。
- 结果表格支持固定表头、横向滚动、选中行、NULL 状态、列宽和统一悬停状态。
- 双击单元格编辑；新增、删除和修改先形成草稿，统一保存或放弃。
- 无主键/唯一键的表保持只读。
- 分页展示当前页、每页数量、上一页、下一页；能获得总数时显示页数和总行数。

## SQL 查询

- 工具栏提供数据库、Schema 和表选择器，以及运行、停止、刷新、CSV 和新建查询。
- Monaco 编辑器与结果区可拖动调整高度。
- 结果表格复用数据预览组件；支持分页、显示列、筛选和查询历史。
- 继续执行超时、取消、最大结果数和危险 SQL 确认规则。

## 表结构编辑

### 字段

支持新增、删除、重命名、排序、类型、长度/精度、主键、非空、默认值和注释。

### 数据库对象

- 支持查看与编辑普通索引、唯一索引和唯一约束。
- 支持查看与编辑外键列、引用表/列以及更新/删除动作。
- 支持查看权限；本轮权限页只读，避免引入身份与授权模型。
- 支持查看规范化 DDL。

### 三阶段执行

1. **预览**：前端提交结构化变更草稿，后端根据数据库方言生成 DDL。
2. **校验**：后端重新读取元数据，验证名称、类型、依赖关系、结构漂移和风险。
3. **执行**：用户确认后携带预览版本标识执行；执行前再次比较结构指纹。

前端不能提交任意最终 DDL 代替结构化变更，避免绕过风险检查。

### 风险规则

- 删除字段/索引/约束、类型收窄、设为 NOT NULL、主键变更和外键变更需要风险确认。
- 删除字段要求输入字段名；删除表和 TRUNCATE 延续现有对象名确认。
- PostgreSQL 尽量在事务内执行全部 DDL。
- MySQL DDL 可能隐式提交，预览页必须提示无法原子回滚；后端逐条记录执行结果并在部分成功时返回明确状态。
- 执行失败后保留前端草稿和数据库错误的安全摘要。

## 后端设计

### 连接注册表

- 增加个人连接分享状态字段或来源查询。
- 团队记录保存来源个人连接 ID、共享人和时间。
- 个人复制记录保存来源团队连接 ID。
- 增加幂等分享和复制端点；旧 import 端点保留兼容期但 UI 不再调用。

### 元数据

统一返回表、列、主键、唯一约束、普通索引、外键、权限、估算行数和规范化 DDL。数据库特有能力通过 capability 字段声明，前端不猜测。

### Schema 变更

- `preview` 接收基础结构指纹和结构化操作列表，返回方言 DDL、风险、警告和预览令牌。
- `validate` 可合并至 preview，但执行端必须独立重复校验。
- `execute` 接收预览令牌与确认信息，验证会话、连接、结构指纹和令牌有效期。
- 审计记录昵称、目标、操作摘要、DDL 摘要、时间和结果，不记录凭证。

## 错误与恢复

- 网络、会话、连接、权限、结构漂移和数据库执行错误使用稳定错误码及中文修复建议。
- 复制/分享遇到重复记录返回成功与现有记录，而不是冲突错误。
- 数据保存精确要求影响一行；结果不符立即停止后续操作。
- DDL 部分成功返回每条语句状态，界面强制刷新结构并标记需要人工检查。

## 视觉系统

- 采用参考图的浅色、克制、数据密集工具风格。
- 双侧栏、40px 标签栏、40px 主工具栏、32–36px 控件、16px 统一线性图标。
- UI 文本使用统一界面字体；SQL、字段类型和技术标识使用等宽字体。
- 少量蓝/青色只用于主操作、选中和状态，不使用装饰渐变或多套按钮风格。
- 所有交互具备 hover、active、disabled、focus 和 loading 状态。

## 实施顺序

1. 工作区外壳、双侧栏、统一组件与个人/团队连接闭环。
2. 对象树与元数据扩展。
3. 数据预览、筛选、排序、列显示、密度和统一分页。
4. SQL 查询分栏、工具栏和结果复用。
5. 字段、索引、关系、权限与 DDL 页面。
6. Schema 草稿、DDL 预览、风险校验和安全执行。
7. MySQL/PostgreSQL 集成测试、视觉验收、灰度部署与回退验证。

## 测试计划

- 单元测试：分享/复制幂等、重复检测、方言 DDL、结构指纹和风险分类。
- API 测试：昵称、会话、目标权限、令牌过期、结构漂移与错误码。
- 前端测试：连接视图、团队弹窗、表格编辑、Schema 草稿、DDL 预览和确认。
- PostgreSQL 集成：建表、字段变更、索引、唯一约束、外键、事务回滚和漂移冲突。
- MySQL 集成：同等能力及隐式提交/部分成功场景。
- 浏览器验收：对应四张参考图的连接、数据、结构和查询页面；覆盖 1280、1440 和宽屏桌面。
- 部署验收：健康检查、静态资源版本、真实 MySQL/PostgreSQL 查询和可回退镜像。

## 验收标准

- 个人与团队连接不会同时常驻展示，且不再出现导入文案。
- 分享后团队列表立即出现一条且重复分享不新增；复制后个人列表立即出现一条且团队记录保留。
- 个人与团队连接使用完全相同的列表视觉骨架。
- 四类参考页面在信息架构、密度、对齐和组件语言上保持一致。
- 数据预览、SQL 查询和表结构编辑均调用真实 API，不出现无功能按钮。
- PostgreSQL 与 MySQL 的支持范围在界面中由能力声明决定。
- 风险 DDL 无法绕过预览、结构漂移检查与确认步骤。
- 全量单元、集成、竞态、构建和浏览器验收通过后才部署生产。
