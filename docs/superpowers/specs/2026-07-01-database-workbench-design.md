# Database Workbench Design

## Problem

公司同事需要通过内网页面连接各自可访问的 MySQL 或 PostgreSQL 数据库，完成类似 Navicat 的日常查询和数据维护。产品不建立账号体系；数据库连接配置由每位用户保存在自己的浏览器中，服务器只负责代连数据库和执行操作。

## Goals

- 通过浏览器完成数据库连接、对象浏览、SQL 编辑、查询执行和结果查看。
- 支持 MySQL 与 PostgreSQL。
- 支持 `SELECT`、`INSERT`、`UPDATE`、`DELETE`、DDL 和显式事务。
- 将连接配置加密保存在浏览器中，由本地解锁密码保护。
- 服务端不持久化数据库密码，并对危险操作、资源消耗和日志泄漏进行防护。
- 提供可复现的容器化部署、健康检查和反向代理配置。

## Non-goals

- 不提供注册、登录、用户、组织或团队权限体系。
- 不提供跨浏览器连接同步或共享连接。
- 不提供 ER 建模、备份恢复、数据同步或数据库监控。
- 第一版不支持 SSH 隧道和用户电脑上的本地 Agent。
- 第一版不支持云端保存连接密码。

## Proposed solution

### Architecture

系统由 React + TypeScript 单页应用和 Go API 服务组成。浏览器通过 HTTPS 与 API 通信；API 服务使用数据库原生驱动，从部署服务器直接连接用户填写的 MySQL 或 PostgreSQL。部署服务器必须具有到目标内网数据库的网络路由；公网数据库需要允许部署服务器的出口 IP。

连接凭证仅在建立连接时从浏览器发送到服务端。服务端为每个匿名浏览器会话创建短期随机会话标识，在内存中维护连接池；连接空闲 30 分钟或用户主动断开后销毁。服务重启后所有连接失效，用户可从浏览器加密存储中重新连接。

### Browser credential storage

- 连接名称、数据库类型、主机、端口、数据库名、用户名和加密后的密码保存在 IndexedDB。
- 用户首次保存密码时创建本地解锁密码。
- 使用 Web Crypto API：PBKDF2-SHA-256 派生 256 位密钥，随机 16 字节盐，600,000 次迭代；密码使用 AES-256-GCM 和随机 12 字节 IV 加密。
- 派生密钥只保留在当前页面内存中，不写入任何浏览器存储。
- 页面刷新或锁定后需要重新输入解锁密码；连续 15 分钟无操作自动锁定。
- 不启用“忘记密码恢复”。忘记解锁密码时只能清除本地连接配置。

本地加密用于降低浏览器存储泄漏风险，不能防御已经能在页面上下文执行脚本的攻击者。因此生产环境必须使用严格的 Content Security Policy、固定依赖版本、禁止不受信任的第三方脚本，并进行 XSS 测试。

### Connection and session flow

1. 用户打开页面，浏览器生成匿名客户端标识。
2. 用户新建连接或解锁浏览器中已有的连接。
3. 浏览器通过 HTTPS 提交连接参数；服务端校验主机、端口和数据库类型。
4. 服务端建立数据库连接并返回不包含凭证的短期连接 ID。
5. 后续查询仅携带连接 ID；密码不重复传输。
6. 用户断开、会话超时或服务关闭时，连接池被关闭并从内存删除。

### Network policy

为避免产品被利用进行内网扫描，部署配置必须提供主机允许列表。默认生产配置只允许管理员明确填写的 CIDR 和域名后缀；禁止回环地址、链路本地地址、云元数据地址和未允许的端口。DNS 解析后再次校验实际 IP，防止 DNS rebinding。公网连接默认关闭，由管理员显式配置允许的目标范围。

### Workbench user interface

界面采用紧凑的深色专业工具风格：

- 左侧：已保存连接、数据库、Schema、表、视图、字段和索引对象树。
- 中间上部：支持多标签页的 Monaco SQL 编辑器。
- 中间下部：结果集、执行消息、影响行数和错误详情。
- 顶部工具栏：连接状态、执行选中 SQL、执行全部、停止、提交和回滚。
- 结果表格支持虚拟滚动、服务端分页、复制单元格/行、列宽调整和 CSV 导出。
- 键盘可完整操作，焦点状态清晰，并尊重 `prefers-reduced-motion`。

### Query execution

- 支持执行选中 SQL；没有选中内容时执行当前语句。
- 默认禁止一次请求执行多条 SQL，用户可在设置中临时启用。
- 默认查询超时 30 秒、结果页大小 200 行、单次最多读取 10,000 行。
- 查询作为可取消任务执行；取消动作调用数据库驱动的取消机制并释放资源。
- 结果分页优先使用驱动流式读取和服务端短期结果游标，不自动改写用户 SQL。
- 大结果导出由服务端流式生成 CSV，遵守超时和最大导出行数限制。
- 历史记录仅存储在浏览器中，包括 SQL、数据库标识、时间、耗时、状态和影响行数；不记录密码。

### Writes, DDL, and transactions

- 支持自动提交和显式事务模式。
- 显式事务提供开始、提交、回滚操作，并在离开页面前提示未提交事务。
- `UPDATE` 或 `DELETE` 缺少顶层 `WHERE` 时强制二次确认。
- `DROP`、`TRUNCATE` 以及数据库级 DDL 要求用户输入目标对象名称确认。
- SQL 风险识别用于提醒而不是安全沙箱；最终数据库权限由用户提供的数据库账号决定。
- 执行完成后显示影响行数、耗时和服务端生成的查询请求 ID。

### Table data editor

- 表数据页按主键稳定分页，并允许插入、编辑和删除单行。
- 没有主键或唯一键的表默认只读，避免错误更新多行。
- 更新与删除语句由服务端根据数据库方言生成，标识符严格转义，值全部参数化。
- 提交前展示待执行变更；执行后校验影响行数恰好为一，否则回滚并报错。

### API boundaries

API 分为连接、元数据、查询、事务和导出五组。每个请求包含匿名会话令牌与短期连接 ID。服务端设置请求体上限、并发查询上限、每会话连接上限、全局连接上限和速率限制。

API 错误返回稳定的错误码、可读消息和请求 ID。数据库原始错误在移除连接串、主机凭证和敏感参数后返回；服务端日志同样执行脱敏。

### Deployment

- Web 与 API 构建为独立容器，通过 Docker Compose 启动。
- 反向代理终止 TLS，只暴露一个站点地址。
- 提供 `/health/live` 与 `/health/ready`。
- 配置通过环境变量注入，包括允许的 CIDR、允许的端口、连接上限、查询超时和公网连接开关。
- 容器以非 root 用户运行，使用只读根文件系统和最小权限。
- 生产环境不内置数据库密码或示例生产连接。

## Alternatives

### Local agent

本地 Agent 能连接部署服务器无法访问的网络，但需要每位同事安装和升级客户端，不符合“打开内网页面即可使用”的目标。第一版不采用，未来可作为可选连接通道。

### Browser direct connection

浏览器无法安全、通用地直接使用 MySQL/PostgreSQL 原生协议，同时会暴露数据库网络与凭证。该方案不采用。

### Persist credentials on the server

服务端保存凭证可以跨设备同步，但在没有身份体系的前提下无法可靠隔离所有权，并扩大泄漏影响面。该方案不采用。

## Risks and mitigations

- **匿名访问被滥用：** 仅部署在受控内网，配合反向代理访问控制、速率限制和数据库目标允许列表。
- **数据库凭证泄漏：** HTTPS、浏览器本地加密、服务端仅内存保存、日志脱敏、严格 CSP。
- **破坏性 SQL：** 二次确认、对象名确认、数据库最小权限建议；明确提醒无法替代数据库权限控制。
- **大查询耗尽资源：** 超时、取消、分页、行数上限、并发上限和全局连接上限。
- **服务端成为网络跳板：** CIDR/域名/端口允许列表、解析后 IP 复核、禁止特殊地址。
- **无账号导致审计能力有限：** 记录匿名会话 ID、请求 ID、目标数据库别名与操作元数据，但不记录 SQL 参数或密码；反向代理可补充公司网络身份信息。

## Testing and rollout

- 单元测试覆盖加密格式、SQL 风险识别、网络目标校验、方言转义、分页和配置解析。
- 集成测试使用临时 MySQL/PostgreSQL 容器覆盖连接、元数据、查询、写入、事务、取消和断开。
- 浏览器端测试覆盖新建连接、锁定/解锁、多标签查询、危险操作确认、表编辑和 CSV 导出。
- 安全测试覆盖 XSS、凭证日志泄漏、SSRF、DNS rebinding、无限查询和并发限制。
- 首先在测试网络部署，只连接测试数据库；验收后再开放生产目标 CIDR。

## Acceptance criteria

- 同事无需登录即可打开内网页面，并连接服务器可访问的 MySQL 或 PostgreSQL。
- 用户可以加密保存多个连接，刷新后通过本地解锁密码恢复，服务端磁盘和日志中不存在数据库密码。
- 用户可以浏览数据库对象、编辑并执行 SQL、停止查询、分页查看结果并导出 CSV。
- 用户可以完成参数化的单行表数据新增、修改和删除。
- 用户可以开始、提交和回滚事务，并在存在未提交事务时收到离开提示。
- 危险 SQL 按规则触发确认，无确认不能执行。
- 不允许的主机、解析后 IP 或端口无法建立连接。
- 查询超时、结果限制、连接限制和并发限制均可配置并经过自动化测试。
- Docker Compose 可在全新服务器上启动服务，健康检查通过，部署文档包含 TLS 与网络允许列表配置方法。
