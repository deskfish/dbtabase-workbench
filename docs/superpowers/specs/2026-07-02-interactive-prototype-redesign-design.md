# Database Workbench 高保真交互原型设计

## 决策

本轮先不修改生产页面，也不部署服务器。先在现有 Vite/React 工程内建立独立原型入口 `/prototype.html`，用固定演示数据完成可点击、可切换、可筛选的高保真桌面原型。原型通过后，再把已验证的布局与组件语言迁回真实业务组件。

对比过三种路线：

1. **独立 React 高保真原型（采用）**：不受现有页面历史 CSS 干扰，交互真实，后续可按组件迁移。
2. 直接继续改生产组件：功能复用最多，但当前样式债务会持续干扰视觉判断。
3. 静态图片稿：视觉最快，但无法验证连接、标签、筛选、弹窗和结构编辑的状态变化。

## 设计目标

- 第一眼明确是桌面数据库管理工具，而不是卡片式管理后台。
- 在 1440px 及以上桌面中，同时看清连接、对象层级和主工作区。
- 信息密度接近参考图，但通过稳定的行高、字号、分隔线和对齐保持可读性。
- 每个操作有明确的 hover、active、disabled、loading 和结果反馈。
- 个人连接只在侧栏展示；团队连接只在弹窗展示；团队记录执行“复制到个人”，不使用“导入”或“迁移”文案。

## 视觉方向

方向是“克制、精确、偏工程工具”的浅色桌面工作台。

- 背景：冷白 `#f7f9fc`，主工作面 `#ffffff`，选中面 `#edf4ff`。
- 主色：蓝 `#246bfd`，仅用于当前标签、主按钮、选中和键盘焦点。
- 状态色：绿 `#16a673`、橙 `#d8860b`、红 `#d64545`，只表达语义。
- 边框：`#dfe5ee`；不使用厚重阴影、装饰渐变或大圆角卡片。
- 字号：界面正文 13px，次级信息 12px，表头 12px，产品标题 14px；SQL 与字段类型使用等宽字体。
- 控件：常规 32px，高优先按钮 34px；图标 16px；表格舒适密度 36px、紧凑密度 30px。
- 标志性动作：任何对象切换都保留上下文。左侧选中节点、顶部标签和工作区标题同时更新，用户始终知道“当前连接 / 数据库 / Schema / 表”。

## 页面骨架

页面固定为四层：

1. **顶部 52px**：产品标识、工作区标签、数据库版本、连接状态和团队身份。
2. **连接栏 260px**：上下文、搜索、个人连接、团队入口和固定底部操作。
3. **对象栏 252px**：数据库切换、Schema 分组、对象类型、数量和表节点。
4. **主工作区**：表身份栏、二级标签、上下文工具栏、数据/结构/查询内容和底部分页状态。

三列均独立滚动。主工作区任何标题、工具栏或表头不得重叠；横向空间不足时只允许数据表内部横向滚动。

## 核心状态

### 个人连接

- 顶部显示“连接：个人连接”、团队数量和刷新。
- 搜索匹配连接名、主机、数据库和类型。
- 列表项完整显示名称、类型、主机、默认数据库和状态；不常驻显示编辑/删除图标。
- 底部固定新建、编辑、删除、分享和个人设置；未选择连接时相应按钮禁用。
- 点击团队入口打开团队连接弹窗，不替换侧栏内容。

### 团队连接弹窗

- 标题为“复制团队共享连接”，副标题明确“仅复制到个人列表，不修改团队记录”。
- 支持搜索、类型、团队和状态筛选，以及刷新。
- 表格列为选择、连接名、类型、主机、默认数据库、分享人、最近同步、状态。
- 支持单行复制与多选批量复制；已在个人的行不可重复选择。
- 底部显示选中数量、取消和“复制选中（N）”。复制完成后行状态即时变为“已在个人”。

### 数据预览

- 表身份栏显示完整表名、数据库类型、行数、字段数、主键和最近刷新耗时。
- 右侧动作包含刷新、复制表名、编辑表结构、导出 CSV、新增行和更多。
- 二级标签固定为数据预览、字段结构、索引、关系、权限、DDL。
- 工具栏包含字段/内容搜索、WHERE 条件、排序、显示列、密度和每页数量。
- 数据表固定表头；选中行使用淡蓝背景；NULL 使用低对比斜体；底部显示总量、耗时、分页和查询历史。

### 表结构

- 沿用相同表身份栏，避免进入结构编辑后丢失上下文。
- 字段页支持新增字段、批量编辑、搜索和列设置。
- 右侧 DDL 预览与校验结果保持独立滚动。
- 修改项使用轻量行标记；保存按钮只在有变更时启用；危险操作显示明确风险而不是只变颜色。

### SQL 查询

- 顶部上下文依次为数据库、Schema、表，再是运行、停止、刷新、导出和新建查询。
- 编辑器与结果区之间有可拖动分隔条。
- 查询结果复用数据表密度、显示列、分页和底部状态语言。

## 原型交互

- 切换连接、数据库、表节点，三处上下文同步更新。
- 切换工作区标签与二级标签。
- 打开团队弹窗，搜索、筛选、选择两行并批量复制，状态与个人连接数量同步。
- 打开/关闭 WHERE 面板，添加条件并应用。
- 切换显示列和紧凑/舒适密度。
- 选择数据行，触发新增/保存/取消的可见状态。
- 进入字段结构，修改字段后显示脏状态与 DDL 预览。
- 进入 SQL 查询，拖动编辑器分隔条并模拟运行反馈。

## 可访问性与动效

- 所有动作使用原生 button/input/select，具备可见 `focus-visible`。
- 图标按钮提供 `aria-label` 和 tooltip；状态不只依赖颜色。
- 弹窗具备遮罩、关闭按钮和 Escape 关闭。
- 动效只用于 120–240ms 的 hover、弹窗进入、面板展开和状态反馈。
- `prefers-reduced-motion` 下移除非必要动画。

## 文件边界

- `web/prototype.html`：独立 Vite 入口。
- `web/src/prototype/PrototypeApp.tsx`：演示数据与页面状态编排。
- `web/src/prototype/components/*`：连接栏、对象栏、工作区、团队弹窗等原型组件。
- `web/src/prototype/prototype.css`：独立设计 token 与布局，不污染生产样式。
- `web/src/prototype/PrototypeApp.test.tsx`：核心状态切换与批量复制交互测试。

## 验收标准

- 在 1440×900 和 1920×1080 下，无元素重叠、截断失控或页面级横向滚动。
- 左侧连接与对象信息层级、主工作区结构、团队弹窗字段与参考图一致。
- 五个核心状态均可通过真实点击进入，不存在纯装饰按钮。
- 原型测试、TypeScript 构建和浏览器控制台检查通过。
- 本轮只提供本地 URL 与截图，不部署 `10.10.80.71`。
